Крипто-инструменты в браузере: генерация пар ключей EC (кривая P-256/secp) и RSA, хэширование (SHA-1/256/384/512), кодирование/декодирование (base64). Всё работает на клиенте (Web Crypto API), ничего не уходит на сервер. Страницы: index.html (главная), ec-keys.html, rsa-keys.html, hash.html; общий код — common.js/common.css.
