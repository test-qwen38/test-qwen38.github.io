Декодер JWT

Разбирает JSON Web Token на части header, payload и signature. Расшифровывает Base64URL-сегменты, показывает claims с проверкой сроков (exp, nbf, iat). Секрет для HS256/HS384/HS512 можно задать в чистом виде или Base64 — подпись проверяется локально, ничего никуда не отправляется.

      Как устроен JWT: BASE64URL(header).BASE64URL(payload).signature.
      Header — тип (typ) и алгоритм подписи (alg).
      Payload — JSON с claims: зарегистрированными (sub, iss, aud, exp, nbf, iat) и произвольными.
      Подпись проверяется по секрету (HMAC) или публичному ключу (RS/ES): для HS256/HS384/HS512 эта страница проверяет её напрямую в браузере (Web Crypto, локально), если указан секрет.
      Секрет можно вставить в чистом виде (используется как есть, UTF-8) или в виде Base64 (декодируется в байты перед HMAC) — режим «Авто» пробует оба варианта и показывает, какой подошёл.
      Токен с alg none не подписан вовсе.
