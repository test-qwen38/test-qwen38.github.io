Декодер JWT (JSON Web Token). Разбирает токен на сегменты header, payload и signature, расшифровывает Base64URL, форматирует JSON claims, показывает алгоритм подписи (alg) и проверяет сроки exp / nbf / iat с бейджами «активен / истёк / ещё не действителен». Автодекодирование при вводе, кнопка с примером токена, копирование decoded JSON. Подпись не проверяется (нужен секрет/ключ) — только расшифровка. Однофайловое приложение (HTML/CSS/JS), всё локально в браузере.
