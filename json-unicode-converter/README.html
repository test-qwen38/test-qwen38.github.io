Конвертер JSON unicode-эскейпов: «Эскейпить» заменяет все не-ASCII-символы на \uXXXX (для кириллицы и emoji — surrogate pairs), «Расэскейпить» возвращает обычные символы для \uXXXX и прочих JSON-эскейпов (\n, \\, \" и т.д.), включая слияние surrogate pairs. Ошибки парсинга не ломают результат — неопознанные последовательности остаются как есть. Один файл (HTML/CSS/JS).
