Кодер/декодер Base64, Base64 URL-safe и Hex. Двусторонние превращения: текст (UTF-8) ↔ байты в выбранном представлении. Опции: перенос base64 каждые 76 символов, включение/отключение padding (=), lowercase/uppercase для hex, разделитель байтов, выбор кодировки при декодировании в текст (UTF-8 / Latin-1). Валидация входных строк с понятными ошибками. Всё выполняется локально в браузере, один файл (HTML/CSS/JS).
