# DOOM 3 — браузерная FPS

Браузерная 3D-шутер в атмосфере оригинального **DOOM 3**. Vanilla JS без сборки и без внешних
ассетов: все текстуры генерируются на `<canvas>`, все звуки — процедурно через WebAudio.
Единственная зависимость — `three.js` (r128) с CDN.

## Как запустить

Открыть `doom-3/index.html` в браузере (нужен интернет для загрузки three.js).
WebGL обязателен. Клик по экрану захватывает мышь (Pointer Lock).

## Геймплей

Заброшенное подземелье 40×32 м с внутренними стенами и потолками. Цель:
1. Найти **ключ** (золотой предмет с подсветкой).
2. Открыть им зелёную дверь выхода на правом краю карты.
3. Дойти до проёма и покинуть уровень.

По пути — 7 врагов. Их можно убивать (не обязательно всех), обходить или отстреливаться.
Ресурсы: аптечки (+25 HP), патроны для обоих оружий.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь | обзор (pointer lock) |
| ЛКМ | огонь |
| R | перезарядка |
| E | подобрать предмет / открыть |
| 1 | пистолет (8/16) |
| 2 | дробовик (5/10) |
| F | фонарик вкл/выкл |
| Shift | бег |
| SPACE | прыжок |
| ESC | пауза |

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Точка входа: canvas + HUD + экраны (меню/пауза/финал) |
| `css/main.css` | Стили HUD, экранов, crosshair, виньетки урона |
| `js/game.js` | Вся игровая логика: сцена, коллизии (AABB), враги, оружие, подбор, цикл |
| `js/audio.js` | Процедурные звуки (стрельба, урон, подбор, перезарядка) на WebAudio |

## Подкач

- **Уровень** описан данными: массивы `WALLS_FULL`, `CEILINGS`, `PICKUPS`, `ENEMIES`, `EXIT`
  в начале `js/game.js` — легко менять расстановку.
- **Враги**: простое AI — видимость через raycast к стенам, преследование, замах
  (`windup`) и выпад с уроном в ближнем бою.
- **Оружие**: 2 вида (пистолет, дробовик с разбросом 7 дробин), разброс,
  трассеры, вспышка, откат, перезарядка.
- **Худ**: здоровье (краснеет ≤ 25), патрон/запас, имя оружия, иконка фонарика.
- **Финал**: экран победа/поражение со статистикой (убито, здоровье, время).

## Примечания

- Разрешение рендера 4:3 (letterbox), как в оригинале; при ресайзе окно остаётся
  4:3 и центрируется.
- Коллизии — AABB с развёрткой по минимуму проникновения (игрок + враги).
- Дверь выхода блокирует, пока не найден ключ; после — анимируется
  распахиванием.
- Звуки создаются лениво после первого пользовательского жеста
  (требование автоплея браузеров).
