Генератор криптографически случайных строк в форматах Hex (lower/UPPER), Base64 и Base64 URL-safe. Байты берутся из crypto.getRandomValues() (CSPRNG браузера), длина задаётся в байтах (1–1 048 576) и конвертируется в символы: hex → 2 × N, base64 → ⌈N/3⌉ × 4 (опционально без padding =). Можно генерировать до 1000 строк за раз, копировать список. Быстрые пресеты: 16/32/64/256 байт (128/256/512/2048 бит). Всё локально в браузере, один файл (HTML/CSS/JS).
